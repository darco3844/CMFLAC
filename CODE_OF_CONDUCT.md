# Code of Conduct

## Our commitment

CMFLAC aims to be a welcoming, respectful, and constructive open-source community. Participation is expected to be free from harassment and discrimination.

## Expected behavior

- Be respectful and considerate.
- Critique ideas and code, not people.
- Explain disagreements calmly and assume good faith.
- Welcome newcomers and help them learn.
- Give actionable feedback.
- Respect privacy and do not publish other people's personal information.
- Follow project rules and applicable laws.

## Unacceptable behavior

- Harassment, threats, insults, or discriminatory language.
- Sexualized attention or unwanted contact.
- Doxxing or sharing private information.
- Trolling, deliberate disruption, or repeated bad-faith behavior.
- Publishing malware, credential theft, or malicious repository extensions.

## Enforcement

Project maintainers may edit or remove content, close discussions, or restrict participation when behavior violates this code. Serious incidents can be reported privately using the contact method in [SECURITY.md](SECURITY.md).

This code applies to project spaces, including issues, pull requests, discussions, and official community channels.
